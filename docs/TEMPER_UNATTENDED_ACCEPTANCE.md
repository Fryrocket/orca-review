# TEMPER unattended acceptance

This lane advances TEMPER without requiring the owner at a computer and without
changing a live interface, account, credential, service, model, or inventory
record.

## Completed automatically

- Run the D-P TEMPER Watch fault matrix with disposable snapshots.
- Simulate network loss, signed-heartbeat failure, MQTT loss and clean recovery.
- Exercise the inventory dataset-to-Hailo-8 plan with synthetic metadata.
- Verify that governed roles do not hold owner approval or deployment authority.
- Verify the opaque-reference credential broker with fake references only.
- Write redacted, append-only, hash-chained run evidence.
- Preserve exact blockers for the next supervised session.

## First production label-set intake

The first real dataset must be derived from the verified ORCA item master. Do not
invent stock. Select a small visually distinct family with stable SKU and barcode
records. The manifest must state the owner-controlled source and license, target
at least 50 images per label, and retain the generated manifest hash.

Before capture, freeze the label IDs, SKU and barcode mappings, camera profile,
eight-scenario quotas and privacy zone. Captured assets require SHA-256, source
hash, perceptual hash, split, dimensions, `has_person=false`, and two distinct
reviewers. ORCA remains unable to train, convert, register, deploy, or mutate
inventory automatically.

## Still requires the owner or physical access

- Choose and physically stage the first real SKU family.
- Capture and complete the second human review of real images.
- Exercise a real network disconnect, service failure and reboot/power-loss event.
- Test the physical barcode scanner, microphone and headset.
- Install and accept the iPhone Keychain MQTT build.
- Approve any real model registry or production deployment.
