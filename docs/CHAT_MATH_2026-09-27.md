# Chat math — deployed

Fry requested math in chat. Added a local standard-library Decimal calculator:
arithmetic, parentheses, integer powers (-100 through 100), sqrt, abs, percentages,
and scientific notation. Precision is 40 significant digits for operations;
inexact results are marked approximate. Percent means divide by 100, not modulo
or automatic financial markup: `50 + 10%` is `50.1`.

Complete explicit expressions (including `what is 15% of 200?`) return the existing
reason-mode response directly without model inference. English word problems use
the model's existing read-only planning/broker path with `math.calculate`. Units,
algebra, symbolic solving, and spreadsheet formulas are not implemented by this
calculator. Model interpretation of word problems can still be wrong.

No eval/exec, filesystem access, shell, or network in calculator implementation.
Bounds: 512 expression characters, 128 AST nodes, depth 32, adjusted decimal
exponents -100 through 100, integer power exponent magnitude at most 100.
Invalid syntax/domain, division by zero, underflow and overflow return an error.
